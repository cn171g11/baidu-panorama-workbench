## 字段与来源

- 来源分别为香港 `baidu_pano:400569` / `baidu_road_member:29`，拉萨 `baidu_pano:132301` / `baidu_road_member:1`。道路成员是百度元数据，不意味着影像已验证。
- 每个新记录保存完整九字段 `extra.originalRecord`，源文件名、源SHA、BD-09说明、YYYYMMDD源日期格式。日期转换为合法ISO日期，不造时钟或时区；源明确日期优先于编码日期。
- 源方向360°规范为等价0°并保留原值；空方向仅由相同本地ID补齐，无本地值保持未知。
- 源flags全部为数值0/0，明确保存false/false，不因为本地记录默认hasPano=true就覆盖。来源类型不等于影像可用认证。
- 同ID时保留完整本地规范行为 `observations[].variant`，链接、pitch、zoom及其他额外字段从本地保留；新文件明确坐标、道路、日期、方向优先，空道路/方向等仅按同ID补齐。
- 本地独有ID保留原规范行，不舍弃、不虚构源记录。全国唯一性由私有SQLite校验，索引不发布。
