# 城市加载反馈与回归边界

## 2026-11-22修复

此前线上有两个确认的缺陷：选省触发的小蓝点下载没有加载框；蓝点城市没有街景collection，选择时调用`selectedKey(undefined)`报错，使地图保留旧结果。街景分片的旧框仅在整片返回后更新，街景结束时即关闭，即使蓝点还在下载；还会与空状态提示重叠。这些不是“测试全过所以网络慢”的结论，而是实际Edge的请求暂停、DOM/computed样式与Runtime证据。

[加载界面](<../city-viewer/index.html>)和[应用逻辑](<../city-viewer/js/app.js>)现在同时覆盖街景和小蓝点：

- 开始读取前先绘制框；下载显示实际接收字节，分片校验通过后更新片数和已校验条数。
- SHA-256、解压、记录校验和地图绘制分阶段显示，不用时间倒计时伪造完成百分比。
- 街景和蓝点有独立任务；一个结束不关闭另一个仍在进行的反馈。蓝点总行数未经去重前不显示虚假的分母。
- 可取消；换省/市/县中止过期请求，迟到结果不会覆盖新选择。取消不会删除此前成功加载的点位。
- 网络10秒仍等待时给慢网提示；[传输模块](<../city-viewer/js/transfer.js>)在30秒无新响应时超时，失败框持续显示并可重试或关闭，而非只显示8秒通知。
- 街景目录先就绪，不串行等待可选蓝点目录。街景县区来自发布目录，不被蓝点目录覆盖。

## 使用方式

- **国内县级街景**：选省、城市仅选目录；继续选有街景条数的县区后自动载入默认首片。多片可切换，全部分片需要内存确认。只选城市不会自动下载整市。
- **小蓝点**：选省开始加载该省原始分片与OSM信息，中央框显示过程。期间可选城市或县区；“OSM蓝点”和“街景”选项明确区分。蓝点仍是独立地图层，不加入普通街景列表。
- **海外普通城市**：选集合后自动载入普通时间分片，没有不存在的OSM县区要求；不下载国内省蓝点。
- 地图点位不等于官方影像认证；只保存元数据，点击点位后仍通过百度官方链接查看影像。

## 真实浏览器门禁

[浏览器回归工具](<../tools/browser_loading_check.mjs>)不依赖正式点位库，复制公开UI白名单并在忽略dist中生成微型合成数据。没有合成点进入归档或发布包。

```powershell
node --max-old-space-size=128 tools/browser_loading_check.mjs --result-dir dist/loading-regression-FRESH
```

真实HTTP分段body与真实gzip/SHA检验覆盖：首次蓝点等待、下载中切蓝城市、已有街景切蓝城市、双任务正反完成顺序、慢网提示、持久HTTP500与SHA失败/重试、关闭、取消与过期请求、在途街景换蓝点县、海外普通城市自动加载、390px布局及真实stalled-body超时。断言computed可见性/非零rect、空状态不重叠、实际绘制阶段与Runtime异常，而不是只检查源码存在框。

[CI部署流程](<../.github/workflows/pages.yml>)额外运行真实国内县级、海外普通城市、蓝点像素、报告与空目录导入回归。发布必须等build/deploy成功，再核对线上版本与实际分片；push或单元测试成功不代表已上线。截图是测试证据，当前vision服务未配置，布局结果依实际浏览器DOM/computed断言，不冒充主观视觉验收。
